# NUNI — Never Up, Never In

Application web progressive (PWA) de scoring collaboratif de sessions de street golf.
Recodage en Flutter de l'application Android LsgScores, avec Supabase comme backend.

Hébergement cible : https://nuni.centuryspine.org (Vercel).

## État

Étape 2 (squelette Flutter web et CI) réalisée. Les étapes suivantes s'enchaînent dans l'ordre du
plan d'ensemble, chacune après validation de son plan par le product owner.

Développer en local : [docs/DEV.md](docs/DEV.md).
